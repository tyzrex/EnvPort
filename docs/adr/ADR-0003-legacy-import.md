# ADR-0003: verified read-only starter import

Accepted 2026-10-28; supersedes the missing-source limitation in ADR-0001/0002.

The user subsequently supplied envport-starter.zip (SHA-256 a0ced89311a942543275f511802a80b8f82cccbbf0ad6d8a8b3eccf996f8d43b). Extracted it into an isolated audit directory, read original documentation/code, ran passing tests/vet and built it with `-buildvcs=false` because the extraction had no Git metadata. The original CLI successfully backed up and restored synthetic files between different checkout paths. Preserve its module path and MIT license.

The exact legacy EVP1 AES-GCM format now has a bounded read-only reader and a compatibility fixture generated by the unmodified starter. Authenticate/checksum all source objects before import, create a new independent age vault/recovery artifact, re-encrypt only in memory, read back and verify new blobs/manifests, CAS-publish a new head, and write a receipt. Never mutate the source key/config/snapshots. Migration imports one selected snapshot into generation one rather than fabricating original ancestry. Legacy lowercase Git identities require careful matching; unsupported identities fail explicitly.

The receipt and source tree equality test establish a reproducible migration/rollback path. Production recovery and external security review still remain necessary.
